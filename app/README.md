# 灵感一现 · 数字分身 V2

将原来的飞书导航升级为可交互工作台：知识树与关联图、技能与方法、认知时间线、带证据的资料复盘、显式采纳行动、实际反馈与增量经验、本人纠正与旧版本保留。

## 数据与权限

- `/` 公开展示虚构交互样例，示例记录保存在浏览器。
- 使用 Sites 提供的 ChatGPT 身份头验证所有者，只有配置的所有者邮箱可读取个人空间。
- 私人材料保存在 Sites R2 `BUCKET` 内，不进入源代码、公开资产或构建产物。
- 所有个人接口 `private, no-store`；所有者写入要求同源与 ETag 并发检查。初始化仅接受独立的服务凭证，且不会覆盖已有资料。
- 旧版导航和飞书入口保留于 `/guide/`，原飞书文档不会被此应用自动修改。

## 当前分析能力

使用已有 AI 提炼、关键词检索与显式整理规则完成证据编译。新输入不会经过在线大模型。界面明确标注“资料关联复盘”；实时模型、飞书自动同步、跨AI平台持续读取及定时推送尚未接入。

## 开发与核验

无需第三方依赖。Node 22+。

```sh
npm run build
npm test
npm run dev
```

`scripts/dev.mjs` 仅为本地 QA 适配器；线上使用 R2。测试覆盖经历到反馈闭环、纠正与停用、重复导入、跨域访问隔离、初始化防覆盖、ETag并发、同源写入和公开资产私密内容检查。

## 运行时配置

- `WORKSPACE_OWNER_EMAIL`：所有者邮箱（运行时 secret）
- `WORKSPACE_SERVICE_TOKEN`：初始化与服务访问凭证（运行时 secret）
- `BUCKET`：由 Sites 绑定的 R2 存储

不把实际配置值、私人种子数据或任何 API Key 写入仓库。新增资料只通过授权的私有接口提交。

## V3 · 个人模型、世界模型与透明系统

- 保留 V2 数据结构，增加可选 `lab.schemaVersion=1`，按需初始化，不覆写原记录。
- 三个入口：个人模型（假设、机制、边界、支持与反例、版本、观察账本），生活推演（四视角状态快照、两方案比较、本人采纳、预测与结果对照），系统逻辑（四层架构、字段与实际实现、数据计数、维护队列、可编辑复核规则）。
- 四大知识领域继续使用 `personal / business / knowledge / build`；目标价值、认知决策、精力情绪、能力机会作为额外观察视角，不替代知识分类。
- `actual / simulation / unknown` 区分记录性质。真实观察仅为本人自述，不等于独立验证。模拟和未确认观察不进入真实计数；推断不计入实际支持证据。同源摘录按一个来源去重，单事件不可重复增加观察。
- 规则默认至少 2 个独立案例、5 次真实观察、7 天回看。数量达标只进入人工复核，不认证人格、不推定因果。规则可修改并保留历史。
- 推演保留所用状态与模型版本；模型暂停或修订后，旧草稿不可直接采纳。反馈保留原预测，不用实际结果覆盖历史预测。
- 写入校验保留已有对象和实验历史，阻止旧页面提交时删除 V3 扩展。所有者权限、ETag、同源写入、独立学习分支保持原有实现。
- 当前是定性、规则辅助的个人模型草案。未连接实时 LLM、向量数据库、模型训练、强化学习或自动生活优化。个人间隔回看由打开页面触发，不发送通知。
- 私人讨论内容通过服务端独立授权路径增量合并，不进入源代码、公开样例、测试 fixtures 或构建产物。新增来源明确标注为检索摘要，不能冒称完整聊天原文。

新增测试覆盖模拟隔离、证据去重、反例保留、人工复核门槛、模型停用/修订、状态快照、方案采纳/反馈、规则历史与旧客户端防覆盖。

## V4 · 随手记与 WorkBuddy 批次接入

- `/api/imports` 接收经过清单校验的消息/分析/附件批次。稳定消息ID、批次内容哈希、D1事务、不可变R2原包，保证幂等、防冲突与来源追溯；新条目一律收件箱、待认领，上传端不能修改既有任务状态。
- 新增随手记使用 D1 的 `capture_*` 关系表，逐条修订、保存版本与分页查询。V3历史空间和经验学习分支保留原R2对象，不在本次强制整库迁移，旧版2MB写入限制仍适用于历史工作区。
- `/api/capture/credentials` 由所有者生成专用上传配置，只在下载响应中返回明文令牌；数据库仅存哈希，可撤销。`CAPTURE_GATEWAY_TOKEN` 是该站点的平台服务访问secret，配合专用应用令牌供上传程序使用；不赋予所有者身份。
- `public/downloads/workbuddy_upload.py` 使用标准Python库，固定批次包、校验、重试和回执。未验证到提交回执不标记已同步。配置不可放入对话或公开仓库。
- 新增随手记收件箱、今日计划、逾期、待排期、五类内容、来源与初步分析、可编辑第一性原理框架、知识候选关联、实际结果、历史版本、日历导出。
- MCP 提供3个只读工具：同步状态、搜索、单条来源与版本读取；内容调用仅所有者或服务授权可访问，上传凭证不可用于这些读取工具。
- `/api/portable` 返回 ZIP：离线 HTML、Markdown、旧工作区JSON、独立经验学习JSON、随手记表及版本JSON、原始批次与附件、校验清单、本地生成SQLite的恢复脚本；不包含上传配置、令牌或令牌哈希。导出48MB上限超限明确失败，不返回缺资料的备份。
- `drizzle/` 为生成的schema-only增量迁移，构建复制到发布包中。`scripts/local-d1.mjs` 是本地QA用的Node SQLite适配器，生产使用D1。
- 限制：没有部署微信采集器、实时LLM、微信/飞书自动提醒、独立账号迁移或静默自动备份。日历文件需自行导入并检查通知权限，完成状态不自动回传。公开页与演示始终不包含个人消息。
