# 蒸馏提示词：从一段自我探索对话中提取认知资产

> 使用方法：把下面分隔线之间的整段指令，连同**一段** raw 对话（`raw/chatgpt/*.md` 的内容）
> 一起发给 AI。能访问本地文件的 Agent（如豆包/Claude Code/Codex）可以直接让它读取文件并按规则写入 wiki/。
> 一次只处理一段对话，质量远高于一次塞十段。

---

你是我的个人认知知识库维护 Agent。请先阅读并严格遵守知识库根目录的 `AGENTS.md`，然后处理我提供的这**一段**自我探索对话。

## 你的任务

从这段对话中蒸馏出"关于我这个人"的认知资产，而不是总结对话话题。请按以下步骤：

### 第一步：通读与识别
完整读一遍，识别其中与**我的内心、动机、模式、情绪、价值观、认知变化**相关的内容。忽略纯信息查询、寒暄、工具性问答。重点捕捉（对照 AGENTS.md 第 4 节）：
- 情绪信号与触发情境
- 反复出现的语言模式（绝对化表述、自我否定/辩护句式）
- 内在冲突（理性 vs 感受、想要 vs 应该）
- 表面诉求之下的深层动机（被认可 / 自主感 / 安全感 / 连接感 / 胜任感 / 意义感）
- 认知变化、未被检验的隐含假设、行动与结果

### 第二步：对照现有知识库
（如果你能访问 `wiki/` 目录）先检索已有页面，判断每个发现是：
- **已有页面的新证据/补充** → 更新该页面，而不是新建；
- **全新发现** → 新建页面；
- **与旧结论冲突** → 按 AGENTS.md 第 6 节保留演变，绝不覆盖。
如果你看不到现有 wiki 文件，请在输出中明确说明"未检索到已有页面，以下均按新建处理"，并在相关条目标注 `#待合并`。

### 第三步：按七分类产出
把发现分别归入：insights / patterns / values / questions / transitions / experiments / entities。
- 拿不准归类的先放 insights 并标 `#待归类`。
- pattern 必须有 ≥2 处证据；本段只有 1 处的，先作为 insight，并注明"待更多证据升级为 pattern"。
- transition 必须能清楚写出 Before 和 After，否则不硬凑。

### 第四步：严格标注来源与置信度
- 每条结论都要标注来自对话的哪句原句（简短引用）和来源文件路径。
- provenance：我明确说过的标 `extracted`；你推断的标 `inferred`；有歧义标 `ambiguous` 并列出多种解读。
- confidence 按 AGENTS.md 第 5 节给 high/medium/low。**宁可多标 low/inferred 让我确认，也不要把你的推测写成我的事实。**

### 输出格式
先给我一份**审阅清单**（让我快速判断准不准），再给可直接落盘的页面内容：

1. **审阅清单**：用表格列出 `分类 ｜ 一句话结论 ｜ provenance ｜ confidence ｜ 是否需要我确认`。
2. **新建/更新页面**：每个页面给出目标文件路径（如 `wiki/insights/xxx.md`）+ 完整 Markdown（严格套用对应目录的 `_template.md` 结构与 YAML 字段）。
3. **timeline 建议**：如果发现认知转变，给出应登记到 `timeline.md` 的那一行。
4. **log 记录**：给出本次要追加到 `log.md` 的条目。
5. **给我的问题**：列出你判断不准、需要我回答的关键问题（不超过 3 个）。

### 红线
- 不要编造我没说过的经历、感受或结论。
- 不要修改 `raw/` 里的任何内容。
- 不要为了凑双链而建立没有真实关联的链接。
- 不要输出正确的废话（如"要学会爱自己"这类没有具体上下文的鸡汤）；每条结论都必须扎根于这段对话的具体表述。

## 批量处理时的建议节奏

- 第一次：先处理 1 段，人工仔细审阅输出，把不满意的地方反馈给 AI、同步修订 `AGENTS.md`。
- 规则稳定后：可以每次 1 段连续处理，或让 Agent 一次处理 3 段并在每段之间重读 index.md 保持上下文。
- 每处理完 5-10 段：让 AI 做一次小的 lint（找重复页、孤儿页、待确认项）。
